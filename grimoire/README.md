# Livre interactif — Exemple

Ce petit projet montre un effet simple de tournement de pages en HTML/CSS/JS.

- Ouvrez `index.html` dans un navigateur (ou servez le dossier avec un live server).
- Remplacez le contenu des `.face` par des images si vous voulez :

```html
<div class="face front"><img src="images/page1.jpg" alt="Page 1"></div>
```

- Boutons `Suivant` / `Précédent` pour contrôler le livre, ou cliquez directement sur une page.

Si vous voulez que j'intègre vos images (l'image fournie), envoyez-la dans le dossier `images/` et je l'insère dans l'exemple.
